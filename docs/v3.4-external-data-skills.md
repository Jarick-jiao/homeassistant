# HomeMate 统一外部数据写入 Skill 能力清单

> 版本：v3.4 ｜ 日期：2026-07-18 ｜ 状态：可用
> 用途：AI 平台（Trae）定时任务定期抓取外部数据，通过本清单定义的 Skill 写入 HomeMate token 保护接口
> 基线：v3.3.9（commit `dc599b1`）｜ 接口文档：`docs/v3.3-API.md`

---

## 一、概述

HomeMate 部分业务数据依赖外部数据源定期插入（新闻、日历、纪念日、休闲活动）。平台已提供 4 类外部写入接口（`/api/external/*`），均通过 API Token + Scope 鉴权。

本文档将这些接口整理为**统一 Skill 能力清单**，供 AI 平台定时任务（Trae Schedule）作为执行手册：AI 按 cron 频率抓取外部数据 → 按 Skill 规范转换 → 调用对应接口写入。

**优势**：
- 替代零散外部脚本（Python + cron），统一鉴权、统一监控
- 复用已有后端接口，无需新增后端代码
- 去重 upsert，重复数据自动合并
- Token 失效时任务失败并通知，不静默失败

## 二、前置准备：创建 API Token

AI 平台写入数据前，管理员需在 HomeMate 创建专用 API Token。

### 2.1 创建步骤

1. 管理员登录 HomeMate（admin/admin123）
2. 进入「⚙️ 管理」Tab → 🔑 API Token 管理 → 「➕ 新建」
3. 填写：
   - 名称：`AI平台定时写入`
   - 权限：按需勾选（建议全选 4 个 scope）
4. 创建后**立即复制明文 Token**（格式 `hm_xxx`，仅显示一次，存储为 SHA256）

### 2.2 Scope 权限矩阵

| Scope | 可写入接口 | 适用数据源 |
|-------|-----------|-----------|
| `news:write` | POST /api/external/news, /news/batch | RSS 新闻源 |
| `calendar:write` | POST /api/external/calendar/events | 外部日历（Google/Outlook） |
| `anniversary:write` | POST/PUT/DELETE /api/external/anniversaries | 纪念日录入源 |
| `weekend:write` | POST /api/external/weekend/proposals | AI 活动推荐 |
| `*` | 全部 | 全能 Token |

### 2.3 鉴权方式（二选一）

```
Authorization: Bearer hm_xxx
# 或
X-API-Token: hm_xxx
```

## 三、Skill 清单（4 个）

### Skill 1 ｜ 新闻定时写入

**接口**：`POST /api/external/news/batch`（批量，单次最多 50 条）
**Scope**：`news:write`
**去重键**：`source_url`（重复自动 upsert，不产生重复记录）

**请求体**（数组，每项）：
```json
{
  "category": "tech",
  "title": "标题",
  "summary": "摘要",
  "content": "正文（可选）",
  "source": "rss",
  "source_url": "https://原文链接（去重键）",
  "image_url": "https://配图（可选）",
  "published_at": "2026-07-18T10:00:00+08:00",
  "is_hot": false
}
```

**category 取值**：tech / world / local / sports / finance / health

**推荐数据源**（RSS）：
- 科技：36kr、少数派、InfoQ
- 时事：澎湃新闻、界面
- 财经：华尔街见闻
- 健康：丁香园

**推荐频率**：每小时 1 次（`0 * * * *`）

**AI 平台执行步骤**：
1. 抓取 RSS feed → 解析为 article 列表
2. 每条提取 title/summary/source_url/published_at/category
3. 转换为接口 schema，source_url 必填（去重）
4. POST /api/external/news/batch，Header 带 Token
5. 记录响应（created/total）到日志

---

### Skill 2 ｜ 日历事件定时同步

**接口**：`POST /api/external/calendar/events`（单条）
**Scope**：`calendar:write`
**去重建议**：按 title + date 去重（前端拉取后比对，已存在则跳过）

**请求体**：
```json
{
  "title": "家长会",
  "description": "期末家长会",
  "date": "2026-07-20",
  "time": "19:00",
  "end_time": "20:30",
  "location": "学校礼堂",
  "event_type": "meeting",
  "is_important": true,
  "reminder_minutes": 30
}
```

**event_type 取值**：meeting / activity / reminder / holiday

**推荐数据源**：
- 学校校历（教务系统/家长群通知）
- 家庭共享日历（Google Calendar iCal）
- 节假日 API（国务院节假日接口）

**推荐频率**：每日 1 次 09:00（`0 9 * * *`）

**AI 平台执行步骤**：
1. 拉取外部日历源（iCal / API）
2. 解析为事件列表
3. 对比平台已有事件（GET /api/calendar/events），按 title+date 去重
4. 新事件逐条 POST 写入
5. 记录新增条数

---

### Skill 3 ｜ 纪念日定时录入

**接口**：`POST /api/external/anniversaries`（单条）
**Scope**：`anniversary:write`
**去重建议**：按 title + date 去重

**请求体**：
```json
{
  "title": "宝宝生日",
  "date": "2026-08-01",
  "type": "birthday",
  "member_id": 3,
  "description": "5岁生日",
  "is_lunar": false,
  "notify_days": 3
}
```

**type 取值**：birthday / wedding / memorial / custom

**推荐数据源**：
- 通讯录生日（家人/亲友）
- 家庭纪念日清单（结婚日/宝宝百天/乔迁）
- 农历转换（ LunarDate API，is_lunar=true）

**推荐频率**：每周一 09:00（`0 9 * * 1`）

**AI 平台执行步骤**：
1. 读取数据源（通讯录/清单文件）
2. 解析为纪念日列表
3. 对比平台已有（GET /api/anniversaries），按 title+date 去重
4. 新纪念日 POST 写入
5. 记录新增条数

---

### Skill 4 ｜ 休闲活动定时推荐

**接口**：`POST /api/external/weekend/proposals`（单条）
**Scope**：`weekend:write`
**去重建议**：按 title 去重

**请求体**：
```json
{
  "title": "公园野餐",
  "description": "周末全家出游",
  "icon": "🧺",
  "category": "outdoor",
  "tags": ["户外", "亲子"],
  "duration": "半天",
  "cost": "低",
  "difficulty": "easy",
  "suitable_for": "全家",
  "weather_req": "晴天"
}
```

**推荐数据源**：
- AI 生成（基于季节/天气/家庭成员偏好）
- 本地活动平台（大众点评/小红书 API）
- 户外攻略（马蜂窝/穷游）

**推荐频率**：每周五 18:00（`0 18 * * 5`）— 周末前推送新方案

**AI 平台执行步骤**：
1. 获取本周天气（GET /api/dashboard/bigscreen 含天气）
2. AI 生成 2-3 个适合的活动方案
3. 对比平台已有（GET /api/weekend/proposals），按 title 去重
4. 新方案 POST 写入
5. 记录新增条数

## 四、AI 平台定时任务配置规范

### 4.1 创建定时任务（Trae Schedule）

每个 Skill 对应一个定时任务。创建时需提供：
- `name`：任务名称（如「新闻定时写入」）
- `cron_expression`：cron 表达式
- `timezone`：`Asia/Shanghai`
- `message`：执行指令（含数据源、接口、token、去重、输出）

### 4.2 message 模板规范

```
任务：<任务名称>
数据源：<RSS URL / API endpoint / 数据文件路径>
目标接口：<POST /api/external/xxx>
服务地址：http://localhost:8080
API Token：<hm_xxx（对应 scope）>
去重键：<source_url / title+date / title>
频率说明：<每小时/每日/每周>

执行步骤：
1. 抓取数据源
2. 转换为接口 schema（字段见 docs/v3.4-external-data-skills.md）
3. 调用目标接口，Header: Authorization: Bearer <token>
4. 记录结果：写入条数 + 失败原因
5. Token 失效（401/403）时通知管理员，不静默失败

输出：执行结果写入日志，包含 created/total 与失败明细
```

### 4.3 频率建议表

| Skill | cron | 说明 |
|-------|------|------|
| 新闻写入 | `0 * * * *` | 每小时整点 |
| 日历同步 | `0 9 * * *` | 每日 09:00 |
| 纪念日录入 | `0 9 * * 1` | 每周一 09:00 |
| 活动推荐 | `0 18 * * 5` | 每周五 18:00 |

## 五、监控与运维

### 5.1 任务执行监控
- AI 平台定时任务执行日志可查（写入条数 / 失败原因）
- HomeMate 侧：管理中心 → 🔑 API Token 管理 → 查看 Token 的 `last_used_at`（每次调用异步更新，确认任务在运行）

### 5.2 失败处理
- 网络超时：重试 3 次，间隔 5 分钟
- Token 失效（401/403）：任务失败 + 通知管理员（不静默失败）
- 数据源不可达：记录失败 + 下次执行重试
- 写入冲突：upsert 机制自动处理（source_url 去重）

### 5.3 Token 轮换
- Token 明文仅创建时显示一次，遗失需撤销重建
- 建议每 90 天轮换：创建新 Token → 更新定时任务 message → 撤销旧 Token

## 六、安全注意事项

1. **Token 明文不落日志**：定时任务的 message 含 Token 明文，仅 AI 平台可见，日志输出时需脱敏
2. **最小权限**：按数据源 scope 创建独立 Token（新闻源只用 news:write），避免全能 Token
3. **source_url 必填**：新闻写入 source_url 作为去重键，缺失会导致重复
4. **速率限制**：批量写入单次最多 50 条，超量分批
5. **数据校验**：AI 平台写入前校验字段格式（日期 RFC3339、category 枚举值）
