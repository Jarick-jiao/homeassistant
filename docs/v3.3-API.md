# HomeMate v3.3 外部接口 API 文档

> 版本：v3.3  
> 更新：外部定时任务插入能力、时事新闻/家庭日历/纪念日展示、休闲活动外部写入、历史数据定期清理

---

## 一、概述

v3.3 新增"外部程序定时写入"能力：外部脚本（RSS 抓取器、日历同步器、纪念日提醒服务等）可定期调用平台接口插入最新数据，前端大屏聚合展示。主要写入接口需 **API Token 认证**，读取接口公开。

### 认证方式

| 方式 | Header | 示例 |
|------|--------|------|
| Bearer Token | `Authorization: Bearer <token>` | `Authorization: Bearer hm_a1b2c3...` |
| 自定义 Header | `X-API-Token: <token>` | `X-API-Token: hm_a1b2c3...` |

### Token 机制

- Token 明文格式：`hm_` + 64 位 hex（32 字节随机数）。
- 存储为 **SHA256 哈希**，明文仅在创建时返回一次，后续无法查看。
- Token 携带 `scopes`（权限范围），支持多 scope 组合或 `*`（全部权限）。
- 支持 `expires_at` 过期时间（可选，0=永不过期）。
- 每次调用自动更新 `last_used_at`（异步，不阻塞请求）。

### Scope 列表

| Scope | 说明 |
|-------|------|
| `news:write` | 写入时事新闻 |
| `anniversary:write` | 写入/修改/删除纪念日 |
| `weekend:write` | 写入休闲活动方案 |
| `calendar:write` | 写入家庭日历事件 |
| `*` | 全部权限 |

## 二、API Token 管理（管理员，需 JWT）

### 2.1 创建 Token

```
POST /api/tokens
```

**请求头：** `Authorization: Bearer <JWT>`

**请求体：**
```json
{
  "name": "RSS同步器",
  "scopes": ["news:write", "calendar:write"],
  "expires_in": 0
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 令牌名称 |
| scopes | string[] | 是 | 权限范围 |
| expires_in | int | 否 | 过期秒数，0=永不过期 |

**响应：**
```json
{
  "code": 0,
  "data": {
    "id": 1,
    "name": "RSS同步器",
    "scopes": ["news:write", "calendar:write"],
    "token": "hm_a1b2c3d4e5f6...",
    "notice": "请妥善保存此 Token，后续无法再次查看"
  }
}
```

### 2.2 列出 Token

```
GET /api/tokens
```

**响应：** 返回 `APITokenView[]`（不含 token 明文，含 `last_used_at`/`expires_at`）

### 2.3 撤销 Token

```
DELETE /api/tokens/:id
```

## 三、公开读取接口（无需认证）

### 3.1 时事新闻列表

```
GET /api/news?category=&limit=&offset=
```

| 参数 | 默认 | 说明 |
|------|------|------|
| category | all | 分类过滤：tech/world/local/sports/finance/health/all |
| limit | 20 | 每页条数（最大 100） |
| offset | 0 | 偏移量 |

**响应：**
```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "category": "tech",
        "title": "v3.3 发布",
        "summary": "...",
        "content": "...",
        "source": "api",
        "source_url": "https://example.com/1",
        "image_url": "https://...",
        "published_at": "2026-07-18T10:00:00+08:00",
        "is_hot": true,
        "created_at": "2026-07-18T10:00:00+08:00"
      }
    ],
    "total": 1,
    "limit": 20,
    "offset": 0
  }
}
```

### 3.2 纪念日列表

```
GET /api/anniversaries
```

**响应：** 返回全部纪念日（按日期升序）

### 3.3 未来纪念日

```
GET /api/anniversaries/upcoming?days=30
```

**响应：** 返回未来 N 天的纪念日，含 `days_until`（距今天数）和 `next_date`（下次日期）

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "title": "宝宝生日",
      "date": "2026-08-01",
      "type": "birthday",
      "days_until": 14,
      "next_date": "2026-08-01",
      "is_lunar": false
    }
  ]
}
```

### 3.4 大屏聚合数据

```
GET /api/dashboard/bigscreen
```

**响应：** 返回 `sections` 数组，含 7 个板块：health / chores / activities / points / news / calendar / anniversary

## 四、外部写入接口（需 API Token）

### 4.1 写入单条新闻

```
POST /api/external/news
```

**Scope：** `news:write`

**请求体：**
```json
{
  "category": "tech",
  "title": "v3.3 发布",
  "summary": "新增外部接口能力",
  "content": "详细内容...",
  "source": "rss",
  "source_url": "https://example.com/1",
  "image_url": "https://...",
  "published_at": "2026-07-18T10:00:00+08:00",
  "is_hot": false
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| category | string | 是 | 分类 |
| title | string | 是 | 标题 |
| summary | string | 否 | 摘要 |
| content | string | 否 | 正文 |
| source | string | 否 | 来源（默认 api） |
| source_url | string | 否 | 原文链接（**去重键**，重复则 upsert） |
| image_url | string | 否 | 配图 |
| published_at | string | 否 | 发布时间（RFC3339 / YYYY-MM-DD HH:MM:SS / YYYY-MM-DD） |
| is_hot | bool | 否 | 是否热点 |

**响应：** `{"id": 1}`

### 4.2 批量写入新闻

```
POST /api/external/news/batch
```

**Scope：** `news:write`  
**限制：** 单次最多 50 条

**请求体：** 数组形式，每项结构同 4.1

**响应：** `{"created": 2, "total": 2}`

### 4.3 写入纪念日

```
POST /api/external/anniversaries
```

**Scope：** `anniversary:write`

**请求体：**
```json
{
  "title": "宝宝生日",
  "date": "2026-08-01",
  "type": "birthday",
  "member_id": 3,
  "description": "5岁生日",
  "is_lunar": false,
  "notify_days": 3
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 名称 |
| date | string | 是 | 日期 YYYY-MM-DD |
| type | string | 否 | birthday/wedding/memorial/custom（默认 custom） |
| member_id | int | 否 | 关联成员 |
| description | string | 否 | 描述 |
| is_lunar | bool | 否 | 是否农历 |
| notify_days | int | 否 | 提前几天提醒（默认 1） |

### 4.4 更新纪念日

```
PUT /api/external/anniversaries/:id
```

**Scope：** `anniversary:write`  
**请求体：** 同 4.3

### 4.5 删除纪念日

```
DELETE /api/external/anniversaries/:id
```

**Scope：** `anniversary:write`

### 4.6 写入休闲活动方案

```
POST /api/external/weekend/proposals
```

**Scope：** `weekend:write`

**请求体：**
```json
{
  "title": "公园野餐",
  "description": "周末全家出游",
  "icon": "🧺",
  "category": "outdoor",
  "tags": ["户外", "亲子"],
  "duration": "半天",
  "cost": "低",
  "difficulty": "easy",
  "suitable_for": "全家",
  "weather_req": "晴天",
  "member_id": 0,
  "member_name": "外部接入"
}
```

**说明：** `created_by` 标记为系统(0)，Tips 字段标注外部来源与推荐人。

### 4.7 写入家庭日历事件

```
POST /api/external/calendar/events
```

**Scope：** `calendar:write`

**请求体：**
```json
{
  "member_id": 0,
  "title": "家长会",
  "description": "期末家长会",
  "date": "2026-07-20",
  "time": "19:00",
  "end_time": "20:30",
  "location": "学校礼堂",
  "event_type": "meeting",
  "type": "meeting",
  "is_important": true,
  "recurrence_rule": "",
  "reminder_minutes": 30,
  "color": "#3b82f6"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 标题 |
| date | string | 否 | 日期 YYYY-MM-DD |
| time | string | 否 | 开始时间 HH:MM |
| end_time | string | 否 | 结束时间 HH:MM |
| location | string | 否 | 地点 |
| event_type | string | 否 | meeting/activity/reminder/holiday |
| reminder_minutes | int | 否 | 提前提醒分钟（默认 30） |
| recurrence_rule | string | 否 | 周期规则（需通过 ParseRule 校验） |

**说明：** `created_by` 标记为系统(0)。

## 五、清理调度（管理员，需 JWT）

### 5.1 调度器状态

```
GET /api/scheduler/status
```

**响应：** `{"running": true, "tasks": [...]}`

### 5.2 手动触发清理

```
POST /api/scheduler/trigger/cleanup
```

**响应：** `{"code": 0, "message": "任务已触发: cleanup"}`

清理日志输出到服务日志，格式：
```
[CLEANUP] 开始清理历史数据...
[CLEANUP] 新闻清理: N 条
[CLEANUP] 通知清理: N 条
[CLEANUP] 积分记录清理: N 条
[CLEANUP] 聊天消息清理: N 条
[CLEANUP] 留言板清理: N 条
[CLEANUP] 设备数据清理: N 条
[CLEANUP] 清理完成，共删除 N 条历史记录
```

### 5.3 清理策略表

| 表 | 保留期 | 条件 | 清理时间 |
|----|--------|------|----------|
| news | 30 天 | `published_at < now-30d AND is_hot=0`（热点保留） | 每日 03:00 |
| notifications | 90 天 | `created_at < now-90d AND read_at IS NOT NULL`（仅已读） | 每日 03:00 |
| points_records | 180 天 | `created_at < now-180d` | 每日 03:00 |
| chat_messages | 365 天 | `timestamp < now-365d`（Unix 秒列） | 每日 03:00 |
| message_board | 180 天 | `created_at < now-180d AND read_at IS NOT NULL`（仅已读） | 每日 03:00 |
| device_data | 90 天 | `received_at < now-90d` | 每日 03:00 |

**注意：**
- 已读通知/留言保留期满才删除，未读通知不清理。
- 热点新闻不清理（`is_hot=1`），便于长期展示。
- 清理任务也可通过 `POST /api/scheduler/trigger/cleanup` 手动触发。

## 六、错误码

| code | HTTP | 说明 |
|------|------|------|
| 0 | 200 | 成功 |
| 400 | 400 | 参数错误 |
| 401 | 401 | 未认证 / Token 无效 / Token 过期 |
| 403 | 403 | 无权限（scope 不足） |
| 404 | 404 | 资源不存在 |
| 500 | 500 | 服务器错误 |

**401 响应示例：**
```json
{"code": 401, "message": "缺少 API Token"}
```

**403 响应示例：**
```json
{"code": 403, "message": "Token 无此操作权限（需要: news:write）"}
```

## 八、外部定时任务接入建议

1. **RSS 新闻同步**：外部脚本每小时抓取 RSS → 调 `POST /api/external/news/batch` 批量写入，`source_url` 作为去重键，重复内容自动 upsert。
2. **日历同步**：外部脚本每日同步外部日历（如 Google Calendar）→ 调 `POST /api/external/calendar/events`。
3. **纪念日提醒**：外部脚本录入纪念日 → 调 `POST /api/external/anniversaries`，平台自动计算距今天数并展示。
4. **休闲活动推荐**：外部 AI/爬虫推荐活动 → 调 `POST /api/external/weekend/proposals`。
5. **清理**：平台每日 03:00 自动执行，无需外部干预；也可手动触发 `POST /api/scheduler/trigger/cleanup`。

### 外部脚本示例（Python + requests）

```python
import requests

BASE = "http://localhost:8080"
API_TOKEN = "hm_a1b2c3..."  # 从管理员获取

# 定时写入新闻
resp = requests.post(
    f"{BASE}/api/external/news",
    headers={"X-API-Token": API_TOKEN, "Content-Type": "application/json"},
    json={
        "category": "tech",
        "title": "今日科技要闻",
        "summary": "...",
        "source_url": "https://example.com/today",
        "is_hot": False
    }
)
print(resp.json())
```
