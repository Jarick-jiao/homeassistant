## 三、未来规划（变更 9/12/15/17/19 归档）

### 变更 9：AI 家庭助手规划
- 当前：基础 chat WebSocket
- 规划：
  - 接入 LLM API（豆包/通义/智谱）
  - 家庭画像上下文（成员健康/日程/积分聚合）
  - 自然语言指令解析（"提醒妈妈明天吃药"→自动创建 reminder）
  - 主动建议（基于健康趋势、天气、日程冲突）

### 变更 12：数据持久化增强
- 当前：SQLite + WAL
- 规划：
  - 数据导出（JSON/CSV/PDF 报告）
  - 自动备份（每日/每周定时备份到 ./backups）
  - 数据迁移工具（支持 PostgreSQL 切换用于多家庭部署）
  - 加密存储敏感字段（API Key 使用 AES-GCM）

### 变更 15：微信扫码登录完整方案
- 当前：WeCom Webhook MVP（仅推送）
- 规划：
  - OAuth2 扫码登录（企业微信/公众号）
  - 绑定流程：扫码 → 回调 → 关联 family_member.wechat_openid
  - 双向交互：用户在微信回复 → 触发 AI 助手 → 推送结果
  - 模板消息：日程提醒/异常告警/投票发起
  - 需要申请微信服务号或企业微信应用

### 变更 17：智能日程调度
- 当前：基础日程 + 周期提醒
- 规划：
  - 冲突检测（同一时段多事件）
  - 智能排程（根据成员空闲时间自动建议时段）
  - 家庭日历视图（月/周/日）
  - 与休闲活动联动（投票确认后自动创建日程）

### 变更 19：多家庭支持
- 当前：单家庭（family_id=1 硬编码）
- 规划：
  - 多租户隔离（JWT 携带 family_id）
  - 家庭邀请码/加入流程
  - 跨家庭数据隔离与权限
  - 适合社区/养老院场景

## 四、技术债与改进项

| 项 | 说明 | 优先级 |
|---|---|---|
| Tailwind CDN 替换 | 生产环境应使用 PostCSS 编译 | 中 |
| Go 版本 | go.mod 标 1.25.1，实际构建用 1.23（sandbox 限制），生产部署需统一 | 中 |
| Garmin Cloudflare 403 | TLS 指纹检测，需 utls 或独立服务代理 | 高 |
| 日志结构化 | 当前 log.Printf，应升级为 zap/zerolog + 等级 | 中 |
| 测试覆盖 | 当前仅浏览器 E2E，应补充单元测试 | 高 |
| 前端框架 | 当前原生 JS，功能增长后可考虑迁移 Alpine.js/Petite-Vue | 低 |

## 五、部署说明

### 构建
```bash
GOTOOLCHAIN=local GOPROXY=https://goproxy.cn,direct go build -o homemate ./cmd/homemate
```

### 配置
- `config.yaml`（gitignored）：AMAP_API_KEY、GARMIN_USERNAME/PASSWORD、WECOM_WEBHOOK
- 环境变量覆盖：HOMEMATE_JWT_SECRET、HOMEMATE_WECOM_WEBHOOK、HOMEMATE_WECOM_ENABLE_PUSH

### 启动
```bash
./homemate  # 监听 :8080，加载当前目录 config.yaml
```

- 用户名：admin
